# RERA Karnataka sample (derived database)

`projects.csv` is a derived subset of RERA Karnataka public project records, taken from the open dataset
https://github.com/Vonter/karnataka-rera-projects (Open Database License 1.0, https://opendatacommons.org/licenses/odbl/1-0/),
which is built from https://rera.karnataka.gov.in. Some individual contents © Karnataka RERA.

This derived database is also made available under the **ODbL 1.0**. Regenerate it with `python3 scripts/fetch-rera.py`.
Pakka is not affiliated with RERA Karnataka. Verify on the official site before making decisions.
